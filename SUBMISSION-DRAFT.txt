Tagline
Recover from a cancelled journey, coordinate the evening, and inspect every simulated step before confirming.

What it does
BackOnTrack explores a small recovery assistant for someone whose travel disruption affects the rest of their evening. In a fictional Amsterdam-to-Utrecht scenario, the user asks for help getting home. The prototype considers travel cost, time available in a mock calendar and an update for a mock household. It selects the fastest route that meets both constraints and explains excluded options.

A lower budget or unavailable route triggers automatic replanning. If no route can meet both constraints, the assistant explains why and refuses confirmation. Confirmation records a mock reservation, calendar update and household notice. The user can inspect the tool trace and export the resulting simulated state.

How it is built
The prototype uses HTML, CSS and JavaScript modules with a small deterministic planner. Budgets use integer cents. State transitions are immutable and constraints are validated. Browser localStorage retains the current scenario; restored traces are reconstructed from that state. The export is a simulated evidence snapshot, not a tamper-proof audit log.

AI-assisted development disclosure
Codex assisted implementation, testing and preparation of this draft. No AI model executes inside the application. The application does not call Alexa+, AWS, transport APIs, real calendars or messaging APIs. Its tool names represent local mock operations. All travel times, costs and household context are fictional. There are no actual bookings, messages, payments or external service actions.

What is distinctive
The interaction keeps a travel change connected to time constraints and household coordination. It shows how changing constraints invalidates previous confirmation, rather than treating each request as an isolated response. The infeasible state is demonstrated as part of the core journey.

Evidence
Fifteen engine tests passed. Browser integration checks confirmed the default bus plan, a €10-budget replacement train, mock confirmation, an infeasible 30-minute scenario, and a downloaded JSON export marked as simulated. See TEST-EVIDENCE.txt for scope and limits.
